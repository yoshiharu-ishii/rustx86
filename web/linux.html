rustx86 — ブラウザで動く 32bit Linux

Rust製x86エミュレータの上で、本物の Linux 6.18 (Alpine) を起動する。 コンソールはシリアル (ttyS0)。起動には1〜2分かかる — デコンプレッサ・ページング・ドライバ初期化・initramfs展開を全部 ソフトウェアでやっているので、実機の一瞬がここでは長い。

RAM

「起動」を押すとカーネルとinitramfsを読み込む

シェルが出たら ls cat /proc/cpuinfo snake vi /tmp/a などが叩ける。画面をクリックしてからキー入力する。 Ctrl-C / 矢印 / Esc もそのまま届く。
