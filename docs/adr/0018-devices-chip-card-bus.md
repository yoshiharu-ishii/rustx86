# ADR-0018: 装置は「なにか」と「どう見つかるか」で分ける — chip / card と bus

- 状態: **決定** (2026-08-15 ユーザー決定)
- 日付: 2026-08-15
- 関連: [ADR-0017](0017-network-isa-first.md) (**決定3を差し替える**)、
  [ADR-0002](0002-devices-and-16bit-unix.md) (装置を作る順)、
  [network.md](../explanation/network.md)

## 背景

ADR-0017の決定3で `core/src/dev/` を**ハードウェアバスごと** (`dev/isa/`, `dev/pci/`)
に分けた。NE2000をISAで作り、PCIのRTL8029で同じ8390コアを使い回すところまでは
その形で通った。しかし装置が増えたところで、**軸が2つ混ざっている**ことが見えた。

- **`dev/isa/` に「ISAの機構」は無い。** 実体は `mem/bus.rs` の `decode_io`
  (固定番地の `match`) で、`isa/` の中身はただの装置の置き場だった
- **そこに居る面々はISAカードではない。** 8259・8254・8042・MC146818・MC6845・
  16550 は**マザーボードに半田付けされたチップ**で、どれもISAの標準化より前の
  部品である。スロットに挿さっていたのは NE2000 だけ
- **`dev/pci/` は装置の種類ではなく「数える仕組み」。** 設定空間・BAR・スロットは
  装置ではなくバスの話で、`isa` と同じ棚に並ぶものではない
- **`mem/bus.rs` が二重人格。** メモリの地図 + I/Oの地図 + 載っている装置一覧を
  持っていて、しかも自分で「アドレスの振り分け (バス)」と名乗っている
- **IRQの配線が `lib.rs` に居る** (`IRQ_TIMER` / `IRQ_KEYBOARD` / `IRQ_NET`)。
  どの装置がどの線に繋がっているかは機械の配線であって、機械の本体ではない

決定的だったのは先の見立てである。virtio (Tier 8) は**ISAでもPCIでもない**ので、
バス別に装置を置く木は3つ目のディレクトリで破綻する。バスは「どう見つかるか」で
あって「なにか」ではない — 装置の分類軸に使えない。

## 決定

**軸を2本に割る。**

1. **`dev/` は「なにか」**
   - `dev/chip/` — **素子**。チップそのもので、番地もバスも知らない。
     機械 (`Machine`) を組まずに単体で試せる
   - `dev/card/` — **基板**。素子 + 基板の都合 (PROMの並べ方・窓の幅・
     バスへの名乗り)。同じ素子に別の基板を着せたのが NE2000 (ISA) と
     RTL8029 (PCI) で、**素子の実装は1つだけ**
2. **`bus/` は「どう見つかるか」** (次の段で実施)
   - `bus/mod.rs` — `decode_io` / `decode_mem` の頂点 + `Devices`
   - `bus/memmap.rs` — メモリ空間の地図 (RAM・VRAM窓・ROM窓)
   - `bus/isa/` — 固定番地の表 + **IRQの配線** + カードの窓 (0x300)
   - `bus/pci/` — 設定空間・BAR・スロット・INTAの経路 + `host_bridge`
   - **ルール: ディレクトリ = バス、ファイル = 地図。例外を作らない**
3. **名乗りはカード、機構はバス。** vendor/device・BAR・INTA# はカードが
   宣言し、設定空間の読み書きの仕組みはバスが持つ ([PR #141](https://github.com/yoshiharu-ishii/rustx86/pull/141) の分け方を踏襲)
4. **`host_bridge` はバス側に残す。** あれは挿すカードではなく**バスの頭**で、
   設定空間の名乗りも「バスが自分を名乗っている」もの。`card/` に置くと
   「挿さっていないのにスロット0に居る」という矛盾が出る
5. **カードは今は「組み立て」で足りる。** 基板の都合がすべて組み立て時に
   決まる (PROMの並び・設定空間の名乗り) 間は、素子を1枚組み上げて返す関数で
   十分である。走行中に基板側の振る舞いが要る装置が来たら、そのときに型にする。
   **無い振る舞いのために器だけ先に作らない**
6. **ISAという呼び名は残すが、注記を書く。** `bus/isa/` の中身は正確には
   「PC/ATの固定番地の流儀」であって、そこに居るチップはISAカードではない。
   書いておかないと次に読む人が「PICはISA装置」と誤解する

ADR-0017の決定3 (バス別ディレクトリ) は本ADRで差し替える。決定1・2・4・5・6
(ISA先行・8390コアの使い回し・coreの境界・A/B 5周・台帳) はそのまま有効である。

## 効果

- **DP8390の原本が1つ**になり、NE2000とRTL8029はPROMの並べ方だけの基板になった
- **素子が機械を要らなくなる**。基板のテストは `Machine` を組まずに書ける
- virtio (Tier 8) の置き場所が自明になる — 素子は `dev/chip/`、窓は `bus/` 側。
  「isaでもpciでもない3つ目」の問題が起きない
- IRQの配線が `lib.rs` から出て、PCIのINTAルーティングと同じ棚に並ぶ (次の段)

## 検証

構造だけの組み替えなので、**外から見える振る舞いが1ビットも変わらないこと**が関門:

- 既存の外形テスト (`core/tests/ne2000.rs` 12本) を**書き換えずに**通す
- スナップショット形式を変えない (`images/linux-booted.snap` が読める)
- **NIC無し起動のビット同一** (ADR-0017の不変条件) と3OS起動回帰の命令数不変
- ネットワークE2E: `netping.mjs` (16bit) / `netlinux.mjs` (32bit・https) /
  速度は `netbench.mjs`
