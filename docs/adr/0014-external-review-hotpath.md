# ADR-0014: 外部レビュー2本を台帳で裁く — ホットパス付帯処理の一掃

- 状態: **記録** (2026-08-13。実装と判定は即日完了)
- 日付: 2026-08-13
- 関連: [ADR-0013](0013-f1c-freeze.md) (JIT凍結・削除 — 本件の前提)、
  [ADR-0009](0009-pgo-shelved.md) (PGO封印 — 本件でも維持)、
  [pitfalls 11](../explanation/pitfalls.md) (ノイズ床±4%)、
  PR #103 (採用) / #104 (棄却・タグ exp/hotpath-batch2)

## 背景

JIT削除 (ADR-0013) 後、bzImageフル ~81 MIPS。自前の最適化候補は
2026-08-13の4連戦 (SoA・跨ぎ連結・SLOTS掃引・語彙拡大 — 全部ワッシュ) で
使い切り、ノイズ床±4% (pitfalls 11) も確立した状態で、外部レビュー2本
(ChatGPT・Gemini) を受領した。

## 方法の決定

1. **レビュー項目は台帳と突き合わせて三分類する**: (a) 新規 (b) 実装済み
   (c) 実測棄却済み。外部レビューは台帳を全部読んでいるとは限らない —
   「もう裁かれた案」を再審しない
2. **1発1〜2%級はバッチ実装して合算で判定する** (pitfalls 11の帰結)。
   勝ったら二分して寄与を割る。負け/ワッシュはバッチごと棄却してよい
   (どの部品も単独で床を超えない見込みだったのだから)

## 分類と処遇 (全項目)

### ChatGPT

| 項目 | 分類 | 処遇 |
|---|---|---|
| ① hitsカウンタのhot path除去 | 新規 | **batch1で採用** |
| ② advance_ip32 / cs_base掴み置き | 新規 | **batch1で採用** |
| ③ Entryメタデータ化 (len_flags: F_MEM/F_CTL) | 新規 | **batch1で採用** — 本丸 |
| ④ 境界検査の省略 | 新規 | batch2で実測 → **棄却** (下記) |
| ⑤ wideメモリのslice化 | 新規 | batch2で実測 → 棄却 (LLVMが畳み済み) |
| ⑥ HotState分離 | 台帳D1と同一 | 0〜数%枠のまま寝かせ |
| PGO復活 | 実測済み・封印中 | **ADR-0009維持** (運用判断を持ち込まない) |

### Gemini

| 項目 | 分類 | 処遇 |
|---|---|---|
| Basic Block化・HashMap回避・TLBフラット化・RMW単一変換・lazy flags | 実装済み | B4/直接マップ/S3/C系/C1 — 台帳参照 |
| Machine::stepの12.4%を統合フラグで圧縮 | 実測棄却済み | B4連結ではしごは69命令に1回に薄まり済み。さらに薄める跨ぎ連結もワッシュ (exp/chain-cross-page) |

| 境界検査の省略 (ChatGPT④と同一) | 新規 | batch2で実測 → 棄却。**ただしwasm側は未判定** (D3として残す) |
| 計測の罠 (タブ税・ウォームアップ・ノイズ) | 実装済み | pitfalls 6/11・タブ税はMessageChannelで解決済み |

## 実測

**batch1 (①②③、PR #103): 7勝1敗・ペア平均-8.3%** (中央値13.1→12.1s、
ベスト11.4s = 85 MIPS)。ノイズ床を明確に超えた採用。

**batch2 (④⑤、PR #104): 2勝4敗2分** — 境界検査は分岐予測が当たり続け、
バイト組立はLLVMが畳み済みで、**どちらも既にタダだった**。実測ゼロ利得で
unsafeを増やす理由は無い。タグ exp/hotpath-batch2 に保全して棄却。

## 教訓 (三度目の実証で規則に昇格)

**OoOが隠すのは「独立な帳簿」だけ。次の値 (ip・分岐先・guard判定・変換) を
作る仕事は、名前が付帯処理でも直列であり、削れば効く。**
B4 (-43%)・受け口の税 (-22%)・batch1 (-8%) は全部この形で勝ち、
帳簿・照合・検査の削減 (B3/B5/C5/跨ぎ連結/batch2) は全部この形で負けた。
レビューを裁くときも「その仕事の結果を誰が待っているか」で分類できる。

## 残りの台帳

- HotState分離 (D1、0〜数%枠)・wasm側の境界検査 (D3 — nativeの棄却は
  wasmに移送しない)・16bit語彙 (ELKS/FreeDOS体感、土俵外)
- PGOはADR-0009の封印を維持 — 「純粋なコード構造だけで100 MIPS」の路線
