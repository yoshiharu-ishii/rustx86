# AIR.COM — G線上のアリアをPCスピーカーで

エミュレータの中のFreeDOSがバッハ (BWV 1068) を演奏するデモ。
`A:\> AIR` で約64秒、何かキーを押すと止まる。

```
bach-air.ly ── Mutopia のパブリックドメイン楽譜 (LilyPondソース)
   │  ly2notes.py  主旋律 (フルート声部) を読み、\relative のオクターブ規則・
   │              タイ・付点を解決して音符表にする。装飾音は55ms格子より
   │              細かいので落とす
   ▼
notes.inc ──── dw PIT分周値, BIOSティック数 ×138音 (生成物、手で編集しない)
   │  air.asm    PIT ch2 + ポート0x61 直叩き。待ちは INT 1Ah + HLT
   ▼             (アイドル早送りが効く行儀のよい待ち方)
AIR.COM ────── 682バイト。fetch-images.sh が fd14games.img に載せる
```

- テンポは4分音符=880ms (≒68 BPM)。**32分音符=BIOSティック2個**になる値で、
  全音価が整数になり丸め誤差が出ない
- MIDIではなく楽譜ソースから変換しているので、ピッチ抽出の劣化ゼロ・決定的
- 焼き直しは `./build.sh` (python3 + nasm が要る)。生成物はコミット済み
