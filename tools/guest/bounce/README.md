# BOUNCE.COM — mode 13h でボールが跳ねる

エミュレータの中のFreeDOSで動く、最初のグラフィックスのデモ。
`A:\> BOUNCE` で橙のボールが藍の壁の中を跳ね回る。何かキーを押すと
テキスト画面に戻る。

1990年前後のDOSゲームの骨格をそのまま小さくしたもので、
エミュレータの側から見ると**Tier 6a の部品が全部通る実地試験**になっている:

| 部品 | プログラムの中の使い方 |
|---|---|
| `INT 10h AH=00` | 13h へ入り、終了時に 03h へ戻る |
| DAC 0x3C8/0x3C9 | 色32=橙・色33=藍を自分で定義 (Bを書くと自動歩進) |
| 0xA0000 | BIOSを呼ばず直接バイトを置く (壁もボールも) |
| 0x3DA bit3 | **毎フレーム垂直帰線の頭を待つ** — これでテンポが70Hzに決まる |
| `INT 16h AH=01` | キーを覗くだけ (待たない)。押されたら AH=00 で取り除いて終了 |

```
bounce.asm ─── nasm -f bin ─── BOUNCE.COM (生成物、コミット済み)
                                  │  fetch-images.sh が fd14games.img に載せる
                                  ▼
                         A:\> BOUNCE
```

焼き直すときは `./build.sh` (nasm が要る)。
